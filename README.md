# 🎥 Video to GIF Converter

A simple Python project that converts an MP4 video into a GIF using the MoviePy library.

## Features

- Convert MP4 videos to GIF
- Easy to use
- Beginner-friendly

## Installation

```bash
pip install -r requirements.txt
```

## Usage

1. Place your video in the project folder.
2. Rename it to `video.mp4`.
3. Run:

```bash
python main.py
```

The converted GIF will be saved as `output.gif`.

## Technologies Used

- Python
- MoviePy
