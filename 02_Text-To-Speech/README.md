# 🔊 Text to Speech Converter

A simple Python project that converts text into speech using the Google Text-to-Speech (gTTS) library.

## Features

- Convert any text into speech
- Supports multiple languages
- Save output as an MP3 file
- Beginner-friendly

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```

## Example

Enter the text:
```
Hello, welcome to Python!
```

Enter language code:
```
en
```

Output:
```
welcome.mp3
```

## Technologies

- Python
- gTTS
